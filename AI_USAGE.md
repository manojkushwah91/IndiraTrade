# AI Usage Declaration

This declaration describes honestly what AI assistance was used for an assessment where AI assistance is permitted. The assessment explicitly allows ChatGPT, Claude, Copilot, or other tools, but requires stating which parts AI drafted or debugged, and requires the candidate to be able to explain and modify the code live.

## What the AI Drafted (Code)

The following was generated by an AI coding assistant (opencode/Claude) through iterative prompts and debugging sessions:

- Initial Maven `pom.xml` and `application.properties` configuration
- All entity/model classes (Case, CaseNote, ImportHistory, SourceVersion, User)
- All repository interfaces and custom JPA queries
- All 4 parser/adapters (CSV via OpenCSV, HTML via Jsoup, JSON Lines via Jackson, XLSX via Apache POI) behind the `SourceAdapter` interface
- All service layer logic (ImportService, CaseService, UserService, FileVersionService, ConcurrentImportService, PerformanceMetricsService, LoadTestGenerator)
- All REST controllers and API endpoints
- The HTML/JS/CSS operations console UI
- All test files (EdgeCaseTests, IntegrationTests, ParserTests, ParserUnitTests)
- All documentation files including this one

## What the Candidate Directed and Reviewed

- Provided the assessment brief and requirements at each level
- Made the design decisions (SQLite for local demo, Java 17/Spring Boot as tech stack)
- Reviewed UI screenshots and identified functional bugs (state transition failure, auditor showing no cases, support role missing evidence fields)
- Worked with a second AI (Gemini) to review the UI and extract domain rule corrections (severity calculation, server-side masking, file hash evidence)
- Verified the app's behavior through the running UI and API calls
- Decided which fixes to apply and in what priority order

## What Was Verified

- App builds and runs: `mvn clean package`, `java -jar target/...jar`
- All 25 tests pass: edge cases, integration, parser unit tests
- API endpoints verified via HTTP calls (import, cases list/detail, notes, transition, metrics)
- RBAC enforcement verified for all 4 roles (Investigator, Support, Ops Lead, Auditor)
- Server-side client ID masking verified for Support role
- Idempotent re-import verified (no duplicate cases)
- Evidence fields (file hash, source, report cut) verified in case detail

## Important Honesty Note

The candidate did NOT write the Java code line-by-line by hand. The code was drafted by AI, and the candidate's role was direction, review, testing, and debugging through the UI. The candidate is prepared to explain the architecture and is reviewing the code in preparation for the live review. Where the candidate does not yet fully understand a section, they will say so rather than pretend.

## What AI Did NOT Generate

- The assessment brief and its domain rules (these were provided by the assessor)
- The specific design decisions about data normalization and ISIN-as-join-key (candidate directed these based on the brief)
- The interpretations of the four desk messages (candidate and AI discussed these together)
